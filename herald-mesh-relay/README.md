# Herald MESH Relay application

This is a production-grade, ready to use, application intended
to form the backbone of a Bluetooth MESH Network.

This provides additional Herald services for Bluetooth LE 
device presence detection, and for programming all MESH nodes
as Herald Venue Beacons for contact tracing (locations) and
navigation (on-phone) support.

## What works today

- Devices can be provisioned and configured to publish presence data
